# 宜宾特固 V3.0 源码交付包

本包是从源码构建的 Vue 3/TypeScript + Go + MySQL 8.4 系统，不附带 Docker 镜像。目标 Linux 主机或 NAS 需要按实际 CPU 架构和存储环境检查后，从包内源码构建应用容器。

有两个初始化版本：

| 版本 | 程序、迁移和功能 | 首次初始化资料 |
|---|---|---|
| V1 带初始化资料 | 与 V2 使用相同的程序源码和数据库结构 | 只附有来源记录的工艺、价格、工资和奖金配置；被明确标记为 `test_only` 的模拟值不是真实报价或工资。没有施工单、工地、票据、收款、库存流水、工资发放、报销或真实员工身份。 |
| V2 干净源码 | 与 V1 相同 | 不含公司、工艺、价格、工资/奖金配置、商品或其他业务 seed。首次启动后只有结构和由管理员显式创建的账号。 |

用户已授权在公开源码中提供经审核整理的工艺、客户收费、工人工资标准和奖金规则。V1 seed 可包含这些目录资料和明确标记的 `test_only` 模拟值；发布前逐项检查 seed 与包清单。原始 Excel、真实员工身份、客户及员工交易流水、工资发放/报销记录、密码、Token、密钥、数据库备份和本地测试凭据不得进入公开快照或源码包。未经审核的工作副本和原始 Excel 应限制在本机访问，不要贴入 issue、工单或聊天。V2 不含业务 seed，可以作为干净源码部署起点。

V1 包内另附数据导入审计和客户报价逐行参考。其中 92 条固定报价由于工艺、计量或收款责任尚不能唯一映射，只供核对，不进入公司活动收费和账单；逐行参考清单不代表这些报价已导入。V2 不包含这两份公司报价审计资料。

部署 Agent 必须先做只读环境盘点，展示将使用的目录、Compose 项目名、端口和数据库卷。为每个主机实例设置唯一且稳定的 Compose 项目名；模板不提供默认名称，未设置时 Compose 应失败退出。除非用户当时明确授权，不要连接或修改任何现有网站、服务器或 NAS。发现目标已有应用、卷、数据库或端口冲突时停止并报告，不自动接管、删除或改名。

若从源码仓库部署，应克隆公开仓库并固定到发布说明给出的 tag/commit。更新时先 fetch 并核对发布内容，使用快进方式更新清洁的源码目录；不得在包含 `.env`、密码、业务备份或本地修改的目录里覆盖文件。

本包 README、初始化清单和 `BUILD-INFO.json` 说明包模式及源码指纹。Linux、Docker、ARM64、具体 NAS 型号、云主机部署和真实数据恢复是否通过，以 [验证报告](docs/验证报告.md) 中的实际记录为准；未记录为通过的项目仍未验证。
