# V3.0 双源码包验证报告

本报告区分本机静态检查、自动化测试和目标环境实测。未在本报告列为通过的项目，仍未验收。

本报告以下验收内容是此前源码包版本的历史记录，其中 V1 seed 数量对应旧基线 `050d992`。当前 seed 数量以仓库现有 `catalog/catalog-seed-v1.json` 和 README 为准；旧 V1 非空库的客户报价升级使用 `backend/API.md` 所述的增量回填命令，不能将本报告中的旧导入结果当作当前回填验证。

## 基础资料

V1 首次初始化清单包含 13 家公司、67 项工艺、44 个工艺小项、39 项固定公司收费（21 项真实报价、18 项固定 `test_only` 模拟价）、44 项确认工资标准（24 项整项、18 项小项、2 项公司工资覆盖）、2 条自动奖金规则、11 档套餐、74 条套餐来源含项和 0 项商品。元创每档套餐含 6 个可映射项目；旭桥与欧派每档 7 个。92 条来源明确但不能唯一映射到现有工艺、计量或收费责任的固定报价仅在 V1 审计参考文档中待确认，不进入活动收费或账单。模拟工资数为 0。

## 发布边界

V1 中 18 条 `test_only` 价格是清楚标记的 1.00 元/㎡隔离测试值，不代表真实报价；工资没有模拟值。另有 92 条无法唯一映射的固定报价只保留在 V1 的审计参考文件中，没有导入活动收费。V2 不含目录 seed 或业务资料。两个包里的中文 Agent 手册链接指向 `docs/`；首次初始化需要显式执行迁移，V1 资料仅由独立导入命令导入，日常启动、Git 更新不会自动重导 seed。源码包不含预制 Docker 镜像。

## 交付物完整性

最终 ZIP 文件名、SHA-256 和共同源码指纹以两个 ZIP 的 SHA256 sidecar 及各自 `BUILD-INFO.json` 为准；包内 `PACKAGE-MANIFEST.sha256` 列出逐文件摘要。V2 必须不含 seed 与 V1 报价审计文档；V1/V2 共同源码指纹相同。此清单不构成目标服务器或 NAS 的部署验收。
