# 初始化与数据说明

## 两种初始化模式

两个源码包共享同一套 Go/Vue 程序、迁移和 Compose 配置。差别只在首次初始化 seed：

| 内容 | V1 带初始化资料 | V2 干净源码 |
|---|---|---|
| 数据库结构和功能 | 完整 | 与 V1 相同 |
| 公司、工艺、小项和单位 | 随包来源清单中的项目 | 空 |
| 公司收费、工人工资与奖金配置 | 当前 V1 的已确认收费及明确配置的工资/奖金；工资未知时保持待配置 | 空 |
| 商品/员工/测试业务数据 | 不导入员工身份或历史业务；没有业务流水 | 空 |
| 管理员 | 通过操作者显式提供的密码创建 | 通过操作者显式提供的密码创建 |

版本2首次迁移只建立数据库结构，不会自动导入目录或默认账号密码。两个版本均不附施工单、工地、交票、收款、库存流水、工资发放、报销、旧库快照、账号密码或本机测试凭据。

用户已授权公开经审核整理的工艺目录、公司客户收费、工人工资标准和奖金规则。当前 V1 seed 的 115 条公司固定收费均已确认，没有 1 元 `test_only` 客户价；旧 `050d992` seed 中的 18 条占位只用于增量回填识别和软停用。不得把真实员工身份、客户或员工交易记录、密码、Token、密钥、数据库备份、本机测试凭据或原始 Excel 放入公开仓库或源码包。公开前检查 seed 清单和包内文件清单，确认只包含获准的目录与价格标准。

## 首次安装顺序

在新建的隔离 Compose 项目和空数据库中按顺序执行：

1. 从 `.env.example` 创建权限受限的私密配置，设置本机从未使用过且之后保持不变的唯一 `COMPOSE_PROJECT_NAME`、库密码、HTTPS 来源和端口；模板中的项目名为空，缺失时 Compose 会失败，不会采用固定默认项目名。
2. `docker compose config --quiet` 检查配置，并从源码构建 `api` 和 `web`。
3. `docker compose up -d --wait mysql` 启动独立 MySQL。
4. `docker compose run --rm --no-deps api init-db` 执行版本化迁移。
5. 仅 V1 执行 `import-catalog-seed`，使用只读挂载的 `catalog/catalog-seed-v1.json`；V2 跳过此步。
6. 使用显式设置的密码执行 `api init-admin`。
7. `docker compose up -d --wait` 首次启动 API 和 Web。

任何一步提示目标数据库非空、导入摘要不同、公司或工艺重复冲突时，停止并核查目标。不得清空表后重试。相同 seed 摘要允许安全识别重复的首次导入；完整 seed 导入仍拒绝非空库。已导入旧 V1 seed 的非空库需要补当前报价时，只能使用 `backend/API.md` 中的 `backfill-catalog-seed`，先只读 dry-run，再把本次确认码与 `--apply` 一起提交。命令不会迁移数据库；先完成目标备份和独立恢复验证，正式库执行另需单独授权。

## 来源与价格语义

V1 初始化清单应携带每个工艺、小项、计量单位、客户价、日常工资、奖金配置和模拟值的来源字段，至少能追到来源文件、工作表、行号、公司、分类和原始单位。工作簿中的套餐包含、免费、赠送、代购/材料、条件价、另议价、纯备注、空价和歧义公司不能自动转换为可收费价格。

当前 seed 没有 `test_only` 客户价格。旧 seed 的模拟占位不是客户报价；回填时仅当稳定 ID、来源、测试标记、100 分金额和未改动字段全部吻合才软停用，并保留历史引用和金额。初始化不得用客户收费推算工人工资，不得重复计入套餐中已包含的客户收费。确认的工资规则优先于旧 Excel 值；未明确的工资/奖金保持待配置，不猜算法。

工资和奖金应分别存储和汇总。施工自动计提、手动奖金、纠正冲销、部分发放和剩余金额的实际范围应以源码迁移、接口、测试和验证报告为准；不能因资料清单有奖金比例就声称相应功能已验收。

## 数量回执

当前 V1 首次初始化清单包含 13 家公司、95 项公共工艺、115 条公司固定收费（保留 21 条旧真实价格，新增 94 条收费身份；全部已确认、0 条 `test_only`）、24 条公共整项工资、18 条公共小项工资、2 条特殊公司工资覆盖、2 条自动奖金规则、2 种商品、2 条公司商品售价、11 档套餐和 74 条覆盖关系。工资未明确处保持待配置。以 `catalog/catalog-seed-v1.json` 为准。

11 档套餐和 74 条覆盖关系单独存储，不计入 115 条按工艺计价的公司收费。新增 94 条公司收费身份对应 92 个唯一固定来源行及必要变体；旧说明中的“92 条未映射”统计已过时。现场条件价、另议价、免费/赠送和纯材料不自动作为逐项公司施工收费。逐行来源仍以审计文件和当前 seed 的来源记录核对，原始 Excel 行数不等于导入条数。

V2 不含 `catalog/catalog-seed-v1.json` 或其他业务 seed。包清单必须证明 V2 中该文件缺失，且两个版本共享源码指纹相同。未完成逐项清点时，本文件不得填写估计数量；应在最终交付前依据实际 seed 摘要更新本节。
