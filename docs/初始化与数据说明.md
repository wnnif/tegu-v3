# 初始化与数据说明

## 两种初始化模式

两个源码包共享同一套 Go/Vue 程序、迁移和 Compose 配置。差别只在首次初始化 seed：

| 内容 | V1 带初始化资料 | V2 干净源码 |
|---|---|---|
| 数据库结构和功能 | 完整 | 与 V1 相同 |
| 公司、工艺、小项和单位 | 随包来源清单中的项目 | 空 |
| 公司收费、工人工资与奖金配置 | 真实明确值和有标记的测试模拟值 | 空 |
| 商品/员工/测试业务数据 | 不导入员工身份或历史业务；没有业务流水 | 空 |
| 管理员 | 通过操作者显式提供的密码创建 | 通过操作者显式提供的密码创建 |

版本2首次迁移只建立数据库结构，不会自动导入目录或默认账号密码。两个版本均不附施工单、工地、交票、收款、库存流水、工资发放、报销、旧库快照、账号密码或本机测试凭据。

用户已授权公开经审核整理的工艺目录、公司客户收费、工人工资标准和奖金规则；V1 seed 中可包含这些资料与已标记的 `test_only` 模拟值。不得把真实员工身份、客户或员工交易记录、密码、Token、密钥、数据库备份、本机测试凭据或原始 Excel 放入公开仓库或源码包。公开前检查 seed 清单和包内文件清单，确认只包含获准的目录与价格标准。

## 首次安装顺序

在新建的隔离 Compose 项目和空数据库中按顺序执行：

1. 从 `.env.example` 创建权限受限的私密配置，设置本机从未使用过且之后保持不变的唯一 `COMPOSE_PROJECT_NAME`、库密码、HTTPS 来源和端口；模板中的项目名为空，缺失时 Compose 会失败，不会采用固定默认项目名。
2. `docker compose config --quiet` 检查配置，并从源码构建 `api` 和 `web`。
3. `docker compose up -d --wait mysql` 启动独立 MySQL。
4. `docker compose run --rm --no-deps api init-db` 执行版本化迁移。
5. 仅 V1 执行 `import-catalog-seed`，使用只读挂载的 `catalog/catalog-seed-v1.json`；V2 跳过此步。
6. 使用显式设置的密码执行 `api init-admin`。
7. `docker compose up -d --wait` 首次启动 API 和 Web。

任何一步提示目标数据库非空、导入摘要不同、公司或工艺重复冲突时，停止并核查目标。不得清空表后重试。相同 seed 摘要允许安全识别重复导入；普通更新期间不再执行 seed 命令。资料如何更改应在系统中通过有权限的管理功能进行，并遵循审计和版本记录。

## 来源与价格语义

V1 初始化清单应携带每个工艺、小项、计量单位、客户价、日常工资、奖金配置和模拟值的来源字段，至少能追到来源文件、工作表、行号、公司、分类和原始单位。工作簿中的套餐包含、免费、赠送、代购/材料、条件价、另议价、纯备注、空价和歧义公司不能自动转换为可收费价格。

只有经逐项核验确定为真正缺价的项目，才可以存在固定 `test_only` 模拟值。模拟值不是客户报价或已确认工资，必须在 V1 数据和运维界面/清单中明确标识。初始化不得用客户收费推算工人工资，不得重复计入套餐中已包含的客户收费。确认的工资规则优先于旧 Excel 值；未明确的奖金算法保持未配置，不猜算法。

工资和奖金应分别存储和汇总。施工自动计提、手动奖金、纠正冲销、部分发放和剩余金额的实际范围应以源码迁移、接口、测试和验证报告为准；不能因资料清单有奖金比例就声称相应功能已验收。

## 数量回执

当前 V1 首次初始化清单包含 13 家公司、67 项工艺、44 个工艺小项、39 项公司工艺收费（21 项真实价格、18 项固定 `test_only` 模拟价格）、44 项确认工资（24 项整项工资、18 项小项工资、2 项特殊公司工资覆盖）、2 条自动奖金规则、11 档套餐及 74 条覆盖关系、0 项商品。工资没有模拟值。模拟价格统一固定为 1.00 元/㎡，仅用于工作簿中已确认存在、单位明确且未被套餐或其他收费包含的缺价项目；它不是实际报价。

套餐和 74 条覆盖关系单独存储，不计入 39 项按工艺计价的公司收费。旭桥和欧派每档套餐各有 7 条来源含项，元创每档各有 6 条；元创原表没有把地面列入套餐，所以地面不会自动免收。原表中另有 92 条固定收费暂不能唯一映射到现有工艺、单位或收款责任，仅保留在 V1 附带的 `docs/客户报价逐行清单.md` 作为待映射参考，不进入活动公司收费或账单。`docs/数据导入审计.md` 记录分类与来源边界。不能唯一归属公司的报价、通用报价、另议/现场条件、免费/赠送、材料代购和含在组合内的项目不会作为逐项公司收费导入。原始 Excel 行数不等于导入条数。

V2 不含 `catalog/catalog-seed-v1.json` 或其他业务 seed。包清单必须证明 V2 中该文件缺失，且两个版本共享源码指纹相同。未完成逐项清点时，本文件不得填写估计数量；应在最终交付前依据实际 seed 摘要更新本节。
